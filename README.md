# Cyber-Attacks Dataset Analysis (Jupyter Notebook)

A data analysis notebook exploring a cyber-attacks dataset using Python, covering data cleaning, exploration, and visualization to uncover patterns in attack types, frequency, and other trends within the data.

## Overview

This project applies core data analysis skills to a real-world-style cybersecurity dataset, using Jupyter Notebook to combine code, output, and explanation in a single readable document. The notebook walks through the full process: loading raw data, cleaning it, exploring it statistically, and visualizing the findings.

## Features

- **Data loading & inspection** — reading the dataset and examining its structure, columns, and data types
- **Data cleaning** — handling missing values, correcting data types, and standardizing inconsistent entries
- **Exploratory data analysis (EDA)** — summary statistics and breakdowns of attack types, frequency, and other key fields
- **Visualization** — charts and plots to make patterns in the data (e.g. most common attack types, trends over time) easy to interpret at a glance

## Tech Stack

- **Language:** Python
- **Environment:** Jupyter Notebook
- **Libraries:** pandas, numpy, matplotlib / seaborn

## Requirements

```
jupyter
pandas
numpy
matplotlib
seaborn
```

Install with:
```bash
pip install jupyter pandas numpy matplotlib seaborn
```

## Usage

```bash
jupyter notebook cyber_attacks_analysis.ipynb
```

Run the cells in order from top to bottom — each section builds on the data loaded and cleaned in the previous one.
